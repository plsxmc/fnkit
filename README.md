# FNKit

> F1–F12 媒体键 / 标准功能键全局切换 —— 一个功能做到极致的 macOS 小件
> 原生 Swift、零第三方依赖、离线可用

## 功能特性

- **全局切换**：媒体键 / 标准功能键一键切换，F1–F12 想用就用
- **跨 App 让位协议**：谁占用谁优先——其他工具占用 fn 功能时自动让位，释放后接管
- **HUD 提示**：切换、占用、释放每一步都有回音
- **独立小件**：与闪截 / BarHub 互不依赖，单独安装单独激活
- **轻量**：常驻内存约 30 MB

## 系统要求

- macOS 13+ · Apple Silicon（arm64 原生）
